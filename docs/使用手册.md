# VoiceTranslator 使用手册

> 面向使用者。5 分钟从安装到"说中文、队友听英文"。

## 1. 安装步骤

### 1.1 装 VB-CABLE 虚拟声卡（一次性）

1. 打开 <https://vb-audio.com/Cable/>，点 **VB-CABLE Driver** 下载
2. 解压，右键 `VBCABLE_Setup_x64.exe` → **以管理员身份运行** → Install Driver
3. **重启电脑**（必须，否则声卡不生效）
4. 验证：按 `Win+R` 输入 `control mmsys.cpl` 回车——播放和录制列表里都应出现
   **CABLE Input / CABLE Output**

### 1.2 装本软件

```bat
git clone https://github.com/<你的用户名>/voice-translator.git
cd voice-translator
python -m venv venv
venv\Scripts\pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
scripts\下载模型.bat      :: 一次性下载全部模型（约 146MB）
scripts\8-图形界面.bat    :: 启动
```

## 2. 界面说明

```
┌─ 运行状态 ────────────────────────────────┐
│ ● 正在监听……（说中文，停顿后出英文）        │  ← 绿点=工作中
├─ 控制 ───────────────────────────────────┤
│   [▶ 开始]  [■ 停止]  [📜 历史记录]         │
├─ 设置 ───────────────────────────────────┤
│ 输入麦克风：[你的真麦克风 ▼]   ← 你对它说话  │
│ 输出麦克风：[CABLE Output ▼]  ← 英文从这出  │
│ 输入音量：▂▃▅▂░░ 18          ← 说话时跳动   │
│ 音量 / 语速 / 灵敏度 三个滑块               │
│ ☐ 本地回放  ☐ 调试模式                     │
│ 全局快捷键：ctrl+alt+t [应用]              │
└──────────────────────────────────────────┘
```

### 2.1 两个"麦克风"下拉框的区别（重要！）

| 下拉框 | 选什么 | 作用 |
|---|---|---|
| **输入麦克风** | 你说话用的真麦克风（耳机麦/USB 麦） | 软件从这里**收**你的中文 |
| **输出麦克风** | **CABLE Output**（虚拟声卡） | 软件把英文"伪装"成这个麦克风**发**出去 |

> ⚠️ 输出麦克风选了真麦克风，对方会听到你的中文原声而不是英文。

### 2.2 Discord 配置（一次性）

Discord → 设置 → 语音和视频 → **输入设备** 选 **CABLE Output**。
其余（输出设备等）保持你原来的设置。

完成后：你说话 → Discord 里对方听到英文。

## 3. 日常使用

1. 双击 `scripts\8-图形界面.bat`（想要开机自启就建个快捷方式放 shell:startup）
2. 点 ▶ 开始（或按 `Ctrl+Alt+T`，游戏里也有效）
3. 对麦克风说中文，**说完停顿约半秒**，英文自动发出
4. 游戏中不想被翻译就按快捷键暂停

### 3.1 滑块怎么调

| 滑块 | 什么时候调 |
|---|---|
| 音量 | 对方反馈英文声音小就调大 |
| 语速 | 默认 1.0x；嫌英文语速慢可调到 1.2x |
| 灵敏度 | 说话没反应 → 往"高"调；不说话乱触发 → 往"低"调 |

### 3.2 有用的开关

- **本地回放**：你自己的耳机里也听到英文（确认翻译效果用，平时建议关）
- **调试模式**：显示识别出的中文、翻译的英文、各环节耗时（排查问题用）
- **历史记录**：所有翻译自动存档，双击可复制英文，可导出 txt

## 4. 常见问题

### Q：对方听到的是中文原声？
Discord 的输入设备没换。必须是 **CABLE Output**，不是你的真麦克风。

### Q：说话完全没反应（输入音量条一直 0）？
1. 输入麦克风下拉框选错了 → 换成你的真麦，点 ↻ 可刷新设备列表
2. Windows 麦克风权限被关 → 设置 → 隐私 → 麦克风 → 允许桌面应用访问
3. 灵敏度太低 → 往"高"调

### Q：输入音量条在跳，但翻译不触发？
环境噪音太大，VAD 一直等你"说完"。把灵敏度往"低"调一点。

### Q：识别出来中文是错的？
- 说话离麦克风近一点，语速正常、吐字清晰
- 背景噪音越小越好
- Moonshine 中文模型对长难句/专业名词偶尔会错，属模型能力边界

### Q：延迟太高？
正常机器端到端约 1.5s（说完停顿后到英文出声）。若明显更慢：
关掉其他吃 CPU 的程序；本软件是纯 CPU 推理，老旧 CPU 上 TTS 环节会慢一些。

### Q：英文听感机械/怪？
TinyTTS 是 1.6M 参数的迷你模型，音质和大型 TTS 有差距——这是"纯本地 +
CPU 实时"的取舍。语速滑块调到 1.1x 左右通常更自然。

### Q：开机报"虚拟声卡未找到"？
VB-CABLE 没装好或没重启。装完驱动必须重启一次电脑。

### Q：软件闪退了？
到 `%APPDATA%\voice-translator\crash.log` 找崩溃日志（记事本打开），
带着日志去仓库提 issue。

### Q：RDP 远程桌面里没有麦克风？
远程桌面默认不重定向录音。mstsc → 选项 → 本地资源 → 远程音频 → 设置 →
"在此计算机上录制" 勾上，重连。

## 5. 隐私说明

- 所有音频**只在你电脑里处理**，不上传任何服务器
- 翻译历史存在本机 `%APPDATA%\voice-translator\history.jsonl`
- 软件联网仅发生在：首次下载模型文件
